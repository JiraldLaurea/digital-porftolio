# Portfolio Website

A modern and responsive personal portfolio built with Next.js to showcase my experience, skills, projects, and contact information.

🔗 Live Demo: https://jiraldcalusay.vercel.app

## 📸 Preview

![Portfolio Screenshot](./public/assets/portfolio_screenshot1.jpg)

## ✨ Features

-   Responsive design
-   Contact form with EmailJS
-   SEO-friendly pages
-   Dark mode
-   Fast performance using Next.js

## 🛠 Tech Stack

-   React
-   Next.js
-   Nodejs
-   TypeScript
-   Tailwind CSS
-   EmailJS
-   Motion
